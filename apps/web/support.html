VoxBridge / Support

Help, from a human.

Most problems are a virtual cable that is not installed, a firewall prompt that was dismissed, or a phone on a different network. Start there.

VoxBridge 1.0.1 · replies usually within two working days

VoxBridge is maintained by a small group of contributors. There is no call centre and no ticket robot. The checklist below resolves most cases in under a minute; if it does not, the form reaches a person.

Before you write

  1. Is a virtual cable installed? Windows needs one before any app can select VoxBridge. Follow step 2 of the setup guide and reboot after installing it.
  2. Did Windows Firewall ask? The first launch prompts for network access. Allow it on private networks. If you dismissed the prompt, open Windows Security → Firewall → Allow an app and enable VoxBridge.
  3. Are both devices on the same network? Guest Wi-Fi and VLANs often block device-to-device traffic. Try USB tethering: enable it on the phone, then connect to the PC's new network adapter.
  4. Did pairing fail? The code changes each time the desktop pairing window opens. Enter the code shown right now, not the one from yesterday.
  5. Is the meter moving on the phone? If the phone meter is flat, the issue is the microphone permission, not the network.

Diagnostics we may ask for

  • Windows: VoxBridge → Settings → Diagnostics → "Copy report". It includes the app version, selected device, sample rate and the last 200 log lines. It never includes audio.
  • Android: Settings → Diagnostics → "Share log", or adb logcat -s VoxBridge if you have a cable and platform tools.
  • iOS: Settings → Diagnostics → "Export log" produces a text file through the share sheet.

Security: security@voxbridge.app — please read the security model first and do not file public issues for exploitable bugs.

Bugs and feature requests

Public issues are welcome at github.com/sdlksdsf/Virtual-Mic/issues. A good report includes the operating system version, the phone model, the connection mode (Wi-Fi, USB or Bluetooth), and the exact text of any error. Screenshots of the diagnostics panel help more than you would expect.

Business and licensing

VoxBridge itself is MIT licensed and free for commercial use. If you bundle it into a product or need a signed enterprise build, write to hello@voxbridge.app with "commercial" in the subject. VB-CABLE has separate commercial terms from VB-Audio.

Response times

Security reports: acknowledged within 72 hours. Everything else: usually two working days, longer around release weeks. If a message needs an answer you can act on, say so in the first line.
