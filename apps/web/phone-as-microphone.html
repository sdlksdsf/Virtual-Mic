VoxBridge / Guide

Your phone is already the best microphone you own.

Laptop microphones sit behind a keyboard and pick up the room. The phone in your pocket has a directional capsule, a noise-cancelling array and a better preamp. This guide covers every practical way to use it as a Windows microphone — and the latency each one costs.

Works offline No account Free and MIT licensed

A microphone is an analogue component with a digital handshake. Windows apps cannot record from a phone directly: they record from a recording endpoint. Every method below is a different way of manufacturing that endpoint. The differences are latency, reliability and what you have to install.

Three ways, honestly compared

ApproachLatencyNeedsVerdict
App over Wi-Fi + virtual cable 60–90 ms Two apps and a driver Best quality per euro. Local-only, works in every app.
USB cable + same app 30–60 ms adb on the PC The flattest path. No radio, no jitter, no discovery.
Bluetooth headset as the mic 150–250 ms Pairing only Fine for calls, bad for live monitoring and music.

Cloud-relay apps — the kind that ask you to install a browser extension and “join a session” — add a server round trip and an account, and they stop working when the vendor does. If your audio never leaves the room, there is nothing to relay and nothing to trust.

Set it up with VoxBridge (10 minutes)

1. Install the Windows app

Download the installer from the download page and run it. It is per-user, so no administrator prompt appears until the optional driver step. SmartScreen will warn once because the build is not code-signed — check the SHA-256 on the download page and choose More info → Run anyway.

2. Give Windows a virtual microphone

Windows applications only see endpoints. VoxBridge renders into VB-CABLE, a well-known virtual audio device, and then points Windows at it. Press Set up virtual mic in Studio: VoxBridge downloads the official installer from vb-audio.com, verifies its Authenticode signature, and runs it. No kernel driver of our own is involved.

3. Install the phone app

On Android, install the APK — the setup guide walks through the “allow this source” prompt. On iPhone the IPA is unsigned on purpose; install it with AltStore, Sideloadly or Xcode using your own Apple ID.

4. Pair the phone

Put both devices on the same Wi-Fi. The phone lists nearby PCs within a few seconds; tap yours and type the four-digit code shown on the desktop, or scan the QR code. Enable Remember this device and the phone reconnects on its own next time.

5. Pick it in the app you care about

VoxBridge makes the cable the Windows default recording device while it is connected, so apps left on Default need no change. If an app pins a device:

  • Zoom — Settings → Audio → Microphone → CABLE Output
  • Teams — Settings → Devices → Microphone → CABLE Output
  • Discord — Voice & Video → Input Device → CABLE Output
  • OBS — Audio Mixer → Mic/Aux → Properties → Device
  • Chrome / Meet — lock icon in the address bar → Site settings → Microphone
Prove it before the meeting. Studio → Test what apps hear records three seconds from the cable's output — exactly what Zoom will receive — and reports the level. If it is silent, you know now, not when someone says “you're muted”.

Getting the sound right

Hold the phone 15–25 cm away and slightly below your mouth. Closer than 5 cm and plosives dominate; further than 40 cm and the room arrives with your voice. Set noise suppression to Medium, presence +4, warmth +3, boost 0, and leave the limiter on. If you use headphones, flip Monitor in the Live header to hear yourself — never with speakers, or the phone will re-record them.

When it goes wrong

The phone does not see the PC

Check the subnet first: guest networks and some mesh systems isolate clients. Then allow VoxBridge on Private networks in Windows Firewall. VPNs on either device also capture local traffic. Still stuck? Use USB with adb reverse, or type the address manually.

Audio is choppy

Raise the jitter buffer to 60–80 ms, move to 5 GHz, and turn off anything saturating the link. If the desktop and router are far apart, USB is the honest answer.

It sounds thin or harsh

Drop suppression to Medium, keep boost at 0 dB and let auto gain work. Move the phone back a little; the capsule is tuned for 15–25 cm, not for talking directly into it.

A shorter version

Install the Windows app, install the phone app, put them on the same Wi-Fi, pair with the four-digit code, choose CABLE Output in the app that needs a microphone. About ten minutes, no account, and the audio never leaves your network.
