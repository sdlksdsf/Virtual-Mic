After you tap download

Installing on a phone.

Four steps, no store involved. iPhone needs a signing tool first — see the sideload guide.

01

Download finishes

Chrome starts VoxBridge-android.apk immediately. It appears in the notification shade when the file is complete.

02

Open the file

Tap the notification, or open Chrome → Downloads / your file manager, then tap the APK.

03

Allow this source

Android asks once: Settings → Allow from this source, then Back and Install. Only the app you opened the file with.

04

Pair and stream

Allow microphone and notifications, pick your PC, enter the four-digit code. In Settings → Background, leave Keep running when locked on.

Before you start

Requirements, plainly.

Windows PC

Windows 10 version 1809 or later, or Windows 11. 64-bit x86. 400 MB of disk space. No administrator rights are needed to install, but the optional VB-CABLE driver install asks for elevation.

Android phone

Android 8.0 or newer with a working microphone. Wi-Fi on the same network, or a USB cable with USB debugging enabled for the flattest path.

iPhone

iOS 16 or newer. Sideloading needs AltStore, Sideloadly or Xcode with any Apple ID. Local Network permission must be allowed on first launch.

Release notes

Version 1.0.0.

Windows

  • Native capture service with WASAPI shared mode, automatic rate conversion and device hot-swap.
  • Virtual microphone detection plus a one-click, signature-checked VB-CABLE setup.
  • Studio chain: noise suppression, gate, auto gain, presence, warmth, compressor, +24 dB boost and a true-peak limiter.
  • Three-second verification test that records from the cable input and reports the level.
  • 16-bit WAV session recording, background operation, autostart, diagnostics export.

Android

  • Foreground service with mute and gain quick actions, live notification and remember-device pairing.
  • 48 / 32 / 24 / 16 kHz capture, PCM16 and IMA ADPCM, 10 or 20 ms frames.
  • Automatic discovery plus manual address and USB/ADB modes.

iOS

  • SwiftUI app with the same protocol, background audio session and local network permission handling.
  • Accelerate-based resampling and the same DSP presets as Android.

Website and infrastructure

  • New site with light and dark themes, download hub, setup guides and legal pages.
  • Anonymous download counters and feedback storage in Supabase, with row-level security.
  • Reproducible Windows, Android and iOS builds in GitHub Actions.
