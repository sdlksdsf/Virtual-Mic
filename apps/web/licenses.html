iOS

The iOS app is written in Swift and SwiftUI and links only Apple frameworks — AVFoundation, Network and SwiftUI — under the Xcode and Apple Developer Program terms. It contains no third-party binary dependencies. Fonts are the same SIL-licensed families bundled with the app.

VB-CABLE

The setup guide recommends VB-CABLE by VB-Audio Software as the virtual audio device. VB-CABLE is not part of VoxBridge, is not covered by the MIT licence, and is not redistributed by us. It is donationware; commercial use requires a licence from VB-Audio. See vb-audio.com/Cable.

Icons and brand

The VoxBridge waveform mark, wordmark, app icons and the interface icon set were drawn for this project and are released under the same MIT licence. Platform logos — Windows, Android, Apple — are trademarks of their owners and are used only to identify the platforms the app runs on.

Website

The marketing site is hand-written HTML, CSS and JavaScript. It uses the same three fonts listed above and two small hosted services: GitHub for release metadata, and Supabase for the anonymous page and download counters and the contact form. There are no third-party analytics scripts, no ad network, no cross-site trackers and no cookie banner, because no tracking cookie is ever set.
