VoxBridge / Setup

Setup, start to soundcheck.

Fifteen minutes if everything goes right, less if your PC already has a virtual cable. Every step below is the same one the desktop app walks you through.

TL;DR Install the Windows app. In Studio, press Set up virtual mic. Install the phone app, join the same Wi-Fi, pair with the four digit code. In Zoom / Teams / Discord choose CABLE Output. Run Test what apps hear. Done.

1. Install on Windows

  1. Download VoxBridge-Setup-1.0.1-x64.exe from the download page.
  2. Run it. SmartScreen may show “Windows protected your PC” because the publisher is new — choose More info → Run anyway only if the file came from the official release page and the SHA-256 matches.
  3. The installer asks where to put the app. Per-user install, no administrator prompt yet.
  4. VoxBridge opens on the Live screen and starts listening. It also offers to start with Windows.

Need a machine without installing? Use the portable build. It runs the same binary without an uninstaller or registry entries.

2. Give Windows a virtual microphone

This is the only part that needs a driver, and it is the same driver every streaming setup already uses. VoxBridge does not ship its own kernel driver — it detects and configures the virtual cable you have.

If a cable already exists

Open Studio. If the endpoint card says a CABLE Input was found, you are done. Pick the exact device with the Output device dropdown if you have more than one.

If nothing exists

  1. Press Set up virtual mic.
  2. VoxBridge downloads the official VB-CABLE package from download.vb-audio.com.
  3. It verifies the Authenticode signature of the installer before anything runs.
  4. Windows asks for administrator permission. Approve it.
  5. Reboot if Windows asks. Then reopen VoxBridge; the endpoint should appear automatically.
What “CABLE Input” and “CABLE Output” mean Apps listen to CABLE Output. VoxBridge writes into CABLE Input. In plain language: the speaker end goes into VoxBridge, the microphone end comes out for Zoom.

Prefer to do it by hand? Use the official VB-Audio page, then return to Studio and press Refresh.

3. Install the Android app

  1. Download VoxBridge-1.0.1-android.apk on the phone.
  2. Open the file. Android asks to allow installs from this source; allow it for your browser or file manager.
  3. Install, then open VoxBridge. Grant microphone permission and, on Android 13+, notification permission so the live controls appear.
  4. If your phone aggressively manages background apps (Xiaomi, Samsung, OnePlus), set VoxBridge to Unrestricted in battery settings so the foreground service is not killed.

4. Install on iPhone

Apple does not allow installing an app that Apple has not signed. The IPA in the release is unsigned, so one of these tools must add a signature with your Apple ID:

  • AltStore / SideStore — installs through a computer with AltServer, renews weekly. Free Apple ID works.
  • Sideloadly — Windows or macOS, sign with a free Apple ID, drag the IPA in.
  • Xcode — build from source with your team selected, then run to the device.

After installing, open VoxBridge and allow Local Network access. Without it, discovery silently fails on iOS.

5. Pair

  1. Both devices on the same Wi-Fi SSID and subnet. A guest network with client isolation will not work.
  2. On the PC open Pair. A four digit code and a QR code appear.
  3. On the phone, the PC appears in the list within a few seconds. Tap it and type the code.
  4. On the desktop, allow VoxBridge through the firewall if Windows asks. Choose Private networks.
  5. Optional: enable Remember this device on the phone so it reconnects without the code.

Nothing discovered? Open Pair → Type an address on the PC, then type that address in the phone app under Connect manually. This bypasses discovery entirely; audio still flows directly.

6. Use it in an app

Open the app that needs a microphone and select CABLE Output (VB-Audio Virtual Cable) as the input. VoxBridge already makes it the Windows default recording device when it connects, so an app set to Default needs no change at all — use the table below only when an app pins a specific device.

AppWhere to change it
ZoomSettings → Audio → Microphone
Microsoft TeamsSettings → Devices → Microphone
DiscordUser Settings → Voice & Video → Input Device
OBS StudioAudio Mixer → Mic/Aux → Properties → Device
Google Meet (Chrome)Lock icon in address bar → Site settings → Microphone
Steam VoiceSettings → Voice → Input device

7. Verify, then tune

In VoxBridge press Test what apps hear and speak for three seconds. A pass means the cable is receiving a signal, which is exactly what Zoom will get. If it fails, the troubleshoot section below has the five usual causes.

Then set comfort levels: noise suppression around Medium, presence +4, warmth +3, and boost at 0 unless you speak quietly. Leave the limiter on.

Troubleshooting

The phone does not find the PC

  • Are both on the same subnet? Mesh systems with a “guest” SSID usually isolate clients.
  • Windows firewall: allow VoxBridge on private networks. Check the network profile is Private.
  • VPNs on either device can capture local traffic. Disconnect and retry.
  • Use manual address entry as a workaround.

The test is silent

  • The endpoint might be wrong. Studio → Output device → pick the one containing “CABLE Input”.
  • Windows volume mixer can mute the cable. Settings → System → Sound → Volume mixer.
  • Reinstall the cable (Studio → Set up virtual mic) and reboot once.

VoxBridge says "No cable" and nothing is routed

  • The app will not play your microphone into your speakers — that is what caused the echo people heard before. Install VB-CABLE from the button on the Live screen, then press Refresh in Studio.
  • A remembered output device can go stale after a driver update. Studio → Output device → Automatic — best virtual cable fixes it.

Audio is choppy or delayed

  • Lower the jitter buffer to 30–60 ms; raise it if loss is happening.
  • Use USB/ADB if the Wi-Fi is congested.
  • Turn off Bluetooth headsets as the capture device; they add 100–200 ms.

It sounds distorted

  • Drop boost to 0 dB and let auto gain work.
  • Move the phone 15–25 cm from your mouth, not 3 cm.
  • Turn noise suppression to Medium; Max can thin out loud consonants.

The stream stops when I lock the phone

  • Update the Android app: from 1.0.0 it holds a foreground microphone service, a wake lock and a Wi-Fi lock for the whole session, and reconnects by itself if the link drops. A locked screen no longer ends the call.
  • Settings → Background → Keep the mic alive when locked must be on (it is by default). The Live header shows a banner when Android is still allowed to sleep the app.
  • Tap Battery there and choose Unrestricted. On Xiaomi, OnePlus, Oppo, Vivo and Samsung also allow Autostart — the button opens the right screen.

Apps list it but I cannot hear anything in my headphones

  • Correct — the cable carries audio to apps, not to your speakers. Flip Monitor in the Live header (or in Studio) if you want to hear yourself, and use headphones: a speaker will feed the phone's microphone and start an echo.

Uninstall

Windows Settings → Apps → VoxBridge → Uninstall. Your recordings stay in Music. VB-CABLE is a separate driver with its own uninstaller in the VB-CABLE folder; removing VoxBridge does not remove the cable, which is deliberate so other apps keep working.

Stuck on a step? Tell us exactly where.

Send the diagnostics file from Studio → Export diagnostics. It is redacted and makes the answer take minutes instead of days.
