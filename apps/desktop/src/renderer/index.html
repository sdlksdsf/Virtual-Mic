Setup

From box to broadcast

  1. 01
    Install the phone app

    Download the Android APK or the iOS build from the website. On iPhone, sideload with AltStore, Sideloadly or Xcode.

  2. 02
    Install the virtual cable

    In Studio, press “Install VB-CABLE”. We fetch the official signed installer, verify it, and run it. A reboot may be required once.

  3. 03
    Pair the phone

    Same Wi-Fi. Open Pair and enter the four digit code on the phone, or scan the QR code.

  4. 04
    Pick VoxBridge in your app

    In Zoom, Teams, Discord or OBS choose CABLE Output as the microphone. Run the 3-second test to confirm.

Voice

Characters and pads

The voice changer runs on this PC, inside the same chain as the denoiser, so it applies to every application that reads the cable — the phone app does not need to know about it.

Pitch moves the note, Formant moves the apparent size of the head. A chipmunk is both up; a demon is both down; a robot is neither, just ring modulation. Amount blends the whole character back toward your own voice.

Natural is a true bypass: no pitch stage, no formant stage, no added latency.

The soundboard plays into the microphone next to your voice, and is added after the character, so the pads always sound like themselves. Eight can overlap; the limiter keeps the sum under the ceiling.

Mute silences your voice, not the pads — a pad is something you pressed on purpose. Stop in the Voice view ends everything immediately, and the pad level slider is independent of the output boost.

Every pad is synthesised on this machine the first time you open the view. No files are downloaded and no microphone audio leaves the PC.

Troubleshooting

When it won’t behave

My phone does not appear in the list.

Check that both devices are on the same subnet. Guest networks and some mesh systems block the UDP broadcast discovery uses. In the phone app choose Connect manually and type the address shown in Pair → Type an address.

Also allow VoxBridge through Windows Defender Firewall on private networks, and make sure the network profile is Private rather than Public.

Apps show “CABLE Output” but I hear nothing.

Run Studio → Can apps hear you. If the test is silent, the capture service may be pointing at the wrong endpoint. Refresh devices and pick a device containing “CABLE Input”.

Windows volume mixer can mute individual cables. Open Settings → System → Sound → Volume mixer and check CABLE Input is not muted.

There is a delay in my voice.

Lower the jitter buffer to 40 ms and pick the Low preset. Use USB/ADB for the flattest path. Bluetooth headsets add 100–200 ms before VoxBridge even sees the audio, so use the phone microphone or a wired headset.

The sound is clipping or distorted.

Set output boost to 0 dB and let auto gain work. The limiter is already holding peaks under −1 dBFS, but stacked boost plus a loud room can still flatten speech. Lower the phone-to-mouth distance slightly.

Antivirus or SmartScreen warns about the installer.

Stable builds are generated by the public GitHub Actions workflow in this repository. SmartScreen warnings appear for any new, unsigned publisher; choose “More info → Run anyway” only if the file came from the official release page. The source is public, so you can build the same binary yourself.

How do I use this in OBS or a browser?

Pick CABLE Output as the microphone source. For browsers, the same device appears in the microphone permission prompt. Chrome sometimes remembers an old device; reset the site permission if it does not switch.

Honest notes

What it can’t do

  • It cannot fix a phone microphone that is physically broken.
  • iOS cannot install a virtual microphone driver — the phone only sends audio, Windows does the routing.
  • Wi-Fi interference adds jitter. USB or 5 GHz Wi-Fi are the reliable choices.
  • Some DRM-protected or exclusive-mode apps may ignore the cable; switch them to shared mode.

Found a bug? Open an issue on GitHub with the diagnostics file attached.
